# VTU 2022 Scheme SGPA & CGPA Calculator 🎓

A simple and user-friendly **VTU SGPA & CGPA Calculator based on the VTU 2022 Scheme**, built using **HTML, CSS, and JavaScript**.

This calculator helps VTU students calculate their **Semester Grade Point Average (SGPA)** and **Cumulative Grade Point Average (CGPA)** easily.

## ✨ Features

* Calculate SGPA according to the **VTU 2022 Scheme**
* Calculate overall CGPA
* Supports subject-wise credits and grades
* Simple and user-friendly interface
* Instant calculations using JavaScript
* Responsive design
* No login or database required

## 🛠️ Technologies Used

* **HTML** – Structure of the calculator
* **CSS** – Styling and responsive design
* **JavaScript** – SGPA and CGPA calculation logic

## 🚀 How to Use

1. Open the calculator in your browser.
2. Select the semester
3. Enter the marks for each subject.
4. Click **Calculate SGPA** to calculate your semester GPA.
5. Enter your semester SGPA values to calculate your overall CGPA.
6. View the calculated result instantly.

## 🎯 Purpose

This project was created to provide **VTU students following the 2022 Scheme** with a simple and convenient way to calculate their SGPA and CGPA.
